G-Network {{ version }} · Windows x64 候选版 · 发布者 Gloria。首次启动不需要配置运行环境；访问服务器需要网络和有效 SSH 凭据。

开始管理一台服务器

  1. 在阿里云等平台准备 Linux 服务器，优先选择 Ubuntu / Debian。确认电脑能访问服务器公网 IP 或内部网络地址。
  2. 在安全组与服务器防火墙放行实际 SSH 端口，通常为 22；建议只允许你的来源 IP。
  3. 点击“添加服务器”，填写地址、端口、SSH 用户名，选择密码、私钥或本机 SSH Agent 认证。私钥文件只在本机读取；不要提供公钥文件或其他机器的密钥。
  4. 保存后测试连接。首次连接请通过云平台控制台等可信渠道比对 SSH 指纹，确认后才会记录；默认开启旧指纹自动更新：已知地址与端口的指纹变化后自动覆盖 APP 记录并提示，表示信任当前握手观察到的新密钥。可在设置中关闭，关闭后变化会拒绝连接。
  5. 选择服务器后查看资源、打开终端或文件管理。工具箱会检查系统、架构与权限；不符合条件的安装项显示原因。

认证方式

密码认证只使用你填写的密码。私钥认证支持 RSA、Ed25519 和 ECDSA 的 PEM / OpenSSH 私钥，受保护的私钥需要填写口令。Agent 认证依赖当前 Windows 会话已配置并加载密钥的 SSH Agent；应用不会替你安装或加载系统 Agent。编辑连接时，同一认证方式的秘密留空可保留已有有效凭据。手动输入的新目标，请先添加到服务器列表并核对主机指纹，再进行节点操作。

Clash 配置工作区

从侧栏打开“Clash 配置”，选择多台服务器并读取节点，批量勾选要导出的节点。随后编辑策略组（手动选择、自动测速、故障转移、负载均衡）及路由规则；规则从上到下匹配，最终由 MATCH 兜底。点击“生成配置”预览完整 YAML，再下载或导入客户端。修改草稿后请重新生成。一次最多 128 个节点、16 个策略组、200 条规则；同名节点自动区分。

节点专属域名分流

点击节点的“专属分流”，为该节点添加一个或多个直连域名，默认包含子域名。例如 baidu.com 同时覆盖 www.baidu.com。保存并生成专属配置后，名单内的域名通过本机网络 DIRECT 连接，其他流量固定经过当前节点。国内出口取决于你电脑所在网络；未添加的域名不会因为属于国内网站就自动直连。

每个节点的名单分别保存在本机，重新打开 APP 并读取节点后可恢复。专属 YAML / Xray JSON 只包含当前节点；切换节点请使用对应节点的配置。普通多节点配置继续使用其全局路由规则。Clash 导入 YAML 后使用规则模式；Xray JSON 在支持完整配置的客户端中使用。VLESS / VMess / SS 原生分享链接不含分流规则。关闭窗口会丢弃尚未保存的域名草稿。

节点与客户端兼容

添加服务器保存的是 SSH 管理信息。需要先完成节点部署或读取已有节点，才会生成 V2Ray 分享链接和 Clash 配置。Clash 本机链接只供同一电脑在 G-Network 运行时获取；跨设备请下载 YAML。协议和内核版本决定兼容性：VLESS、Reality、SS2022 需要支持相应功能的 Mihomo / Meta；Reality 需额外检查服务端版本。不要把节点链接发送给未授权人员。

备份和换电脑

在设置中选择普通备份，可导出无登录秘密的服务器列表。导入后点击“编辑连接 / 补充凭据”。需要迁移登录秘密时，选择口令加密备份并设置强口令。新电脑的导入过程不会替你信任 SSH 主机身份，不会覆盖已有同地址连接的凭据，已有 API Key 默认保留。

升级和诊断

更新检查由你主动触发。公开更新源和签名未配置时，界面会提示暂未开通；下载到本机的更新还需要通过完整性与发布者签名校验。更新不自动启动安装，先等待远程任务完成再退出程序并运行安装器。诊断文件可自行检查后交给支持人员，不会自动发送。

连接失败时

  • 超时：检查 IP、SSH 端口、安全组、服务器防火墙和当前网络。
  • 认证失败：核对用户名、密码，或私钥及私钥口令；确认目标服务器允许该认证方式。
  • 主机身份改变：先通过云平台等可信渠道核对服务器身份，避免直接忽略验证。
  • 工具不可用：查看系统兼容提示。普通 SSH 可管理的系统，不代表所有安装脚本都适用。
  • 启动提示 WebView2 缺失：从 Microsoft 官方页面安装运行时；完整版安装器可在安装时处理此依赖。

数据位置与卸载

为了兼容升级，个人数据仍保存在 %LOCALAPPDATA%\FLNetwork\data。安装目录与个人数据目录分离。升级和卸载都保留个人数据；DPAPI 配置不能直接当作跨电脑备份，请使用应用的导出功能。
