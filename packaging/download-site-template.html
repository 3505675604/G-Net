01 / CONNECT

连接你自己的服务器

兼容可访问的 Linux SSH 主机。支持私钥口令与首次主机指纹核对，适合管理阿里云等平台的个人服务器。

02 / MANAGE

终端、文件与工具

在同一界面查看资源、传输文件和执行工具任务。安装前显示系统与权限要求，避免误用不兼容的脚本。

03 / CONTROL

批量导入，统一编排

Clash 工作区支持链接、Base64 和 YAML 导入，集中管理 VLESS、VMess、Trojan、SS、Hysteria 2 与 TUIC 节点。导入预览会说明不支持的内容。

04 / CHAIN

看得见的代理链

按入口到出口排列节点，创建多跳链路，再交给策略组独立选择。配置导出使用 Mihomo dialer-proxy，保留节点单独使用的方式。

05 / ROUTE

业务分流与 DNS

06 / KEEP

配置留在你的电脑

工作区草稿在本机加密保存，方便重新打开继续编辑。导出的 YAML 含节点连接信息；新协议、代理链和部分高级配置需要匹配的 Mihomo 内核。

BEFORE YOU START

开始之前，了解这些

可以连接国内阿里云服务器吗？

可以，需要电脑能访问该主机的 SSH 端口和有效认证信息。部分安装功能限 Ubuntu / Debian，应用会显示兼容提示。

支持所有电脑吗？

当前发布 Windows x64 版本。macOS、Linux 和原生 ARM 版本尚未发布；企业设备也可能受到安全策略限制。

Clash 配置能发给其他设备吗？

可传输导出的 YAML 文件，也能在本机保存草稿后继续编辑。本机链接要求同一电脑且 G-Network 正在运行；它不是公网订阅。新协议与链式代理需要匹配的 Mihomo 内核。

会自动上传服务器密码吗？

应用在本机保护管理凭据。备份、诊断和更新由你主动操作；Microsoft WebView2 的数据处理和更新适用 Microsoft 自身的政策。
