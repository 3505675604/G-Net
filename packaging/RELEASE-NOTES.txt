G-Network 0.4.0 · Windows x64 候选功能版
发布者：Gloria
官网：https://glorianet.fun/

新增：
- Clash 工作区重新编排为配置来源、链式代理、策略组、路由规则、节点分流、DNS 与端口、生成与保存七页。
- 批量导入 VLESS、VMess、Shadowsocks、Trojan、Hysteria2、TUIC 分享链接、Base64 订阅文本和 YAML；选择合并节点或继续编辑完整配置。
- 完整导入先预览；不支持的 providers、逻辑规则或扩展配置会明确列出，不允许静默丢弃后替换原配置。
- 可编辑多跳链式代理，策略组和域名规则可选择链式出口；缺跳和循环会阻止生成。
- 域名批量分流、AI 与流媒体预设、DNS 和高级配置编辑；保留导入的传输、加密及证书设置。
- 本机保存和恢复整份工作区，节点凭据与配置使用 Windows 用户账户绑定的 DPAPI 加密；版本检查避免覆盖其他编辑。
- 节点专属分流：为每个节点分别保存多个直连域名；覆盖域名及其子域名，其余流量固定走该节点。
- 专属配置可导出 Clash / Mihomo YAML 与 Xray 客户端 JSON；配置仅包含当前节点，名单不会混入其他节点的路由。
- 域名批量输入、去重、删除、开关与本机保存；刷新或重新打开程序后重新读取节点可恢复已保存名单。
- DIRECT 使用客户端所在电脑的网络；国内出口取决于本机网络位置。原生 VLESS / VMess / SS 分享链接不能携带这些分流规则。
- 独立 Clash 配置工作区：跨服务器批量读取、筛选和选择节点，合并到一份完整 YAML。
- 策略组支持手动选择、自动测速、故障转移和负载均衡；可编辑成员、健康检查及规则引用。
- 路由规则可添加、编辑、排序、删除，支持域名、IP 网段、GEOIP、目标端口和最终 MATCH。
- 提供模板、完整 YAML 预览、复制、下载及本机 Clash 导入链接。一次最多 128 节点、16 组、200 规则。
- SSH 默认自动替换已知地址和端口的旧指纹，设置可关闭；首次未知身份仍需确认。自动更新表示信任当前握手观察的密钥，无法证明变更来自管理员。
- 实际 SSH 连接仍核对刚观察的密钥，第二次变化会在认证前拒绝。其他服务器、端口和系统信任文件保持独立。
- 安装器自动选择默认目录，也可在首次安装与升级的目录页更改位置；个人数据仍保存在用户目录。

保留：
- Xray 临时配置验证显式指定 JSON，修复 Failed to get format。
- Edge 仓库密钥非交互导入，修复 gpg cannot open /dev/tty，失败保留旧文件。
- 事务部署、失败回滚、服务器管理、终端、文件管理、备份与诊断。

使用：
- 退出旧版本后运行 0.4.0 安装器，选好目录，再从开始菜单打开 G-Network。
- 普通安装包适用于已有 WebView2 或可以联网安装运行时的电脑；完整安装包包含官方 x64 WebView2。
- 从“Clash 配置”选择服务器、读取节点、编辑组和规则，再生成并导出。
- 点击节点的“专属分流”，添加直连域名，再保存并生成该节点配置。导入支持完整配置的客户端；Clash 使用规则模式。
- 本机导入链接仅适用于同一电脑，需保持 APP 运行；跨设备请使用 YAML。
- VLESS / Reality / SS2022 需要兼容的 Mihomo 内核；不能保证所有旧版 Clash 支持这些协议。
