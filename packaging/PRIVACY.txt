G-Network 隐私与本地数据说明
版本：2026-10-05    发布者：Gloria

1. 本地保存
服务器地址、SSH 用户名、登录凭据、API 设置和 SSH 主机身份记录保存在当前 Windows 用户的数据目录。为兼容旧版，该目录继续为 %LOCALAPPDATA%\FLNetwork\data。密码、SSH 私钥、私钥口令及 API Key 使用当前 Windows 用户的 DPAPI 保护。启动日志也保存在此目录。升级和卸载保留用户数据。

主动保存的 Clash 工作区包含节点连接凭据、策略组、路由规则及 DNS 配置，整份内容使用 DPAPI 加密后保存在本机 clash-profiles.json。该文件只能由原 Windows 用户恢复，不随程序安装包分发。导入文本在本机解析，预览暂存内存；不会抓取远程订阅或自动修改第三方 Clash 配置。

2. 网络请求
管理操作会直接连接你填写的服务器。你主动安装远程工具时，目标服务器可能从相应厂商或软件源下载文件；使用已配置的 AI 服务时，相应工具可能连接该服务。G-Network 不设置远程账号中心，不主动上传服务器列表或管理凭据，不包含使用统计、广告或自动发送诊断的功能。

你主动点击检查更新时，若发行版本已配置更新源，应用才向该 HTTPS 更新源请求版本信息。经你再次操作后，应用可下载并验证更新文件。下载不自动启动安装。更新源可接收到正常网络请求信息（如来源 IP）。本候选版本尚未启用公开更新源。

Microsoft WebView2 Runtime 的安装和后续更新由 Microsoft 组件处理，适用 Microsoft 自身的条款和隐私政策。G-Network 不控制该组件的更新机制。
WebView2 包含默认启用的 Microsoft Defender SmartScreen；该组件可能根据 Microsoft 隐私声明收集并发送使用者信息。详情：https://aka.ms/privacy 和 https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen 。运行时的许可条款随完整安装包提供，安装前请阅读并确认。

3. 导出与备份
普通备份仅包含服务器名称、地址、端口和认证方式等元数据，不含登录秘密或 API Key，导入后需要重新提供凭据。口令加密备份可包含这些秘密；请使用强口令、妥善保存备份，遗失口令无法恢复。诊断文件只包含应用版本、系统与资源检查、脱敏统计，不含服务器地址、用户名、密钥、任务输出或原始日志；不会自动发送给发布者。

V2Ray 分享链接和 Clash YAML 含节点连接凭据。导出、复制、发送给其他人后，这些凭据的流向由你决定。本机 Clash 配置地址仅在同电脑、应用运行且令牌有效时可获取。

4. 删除与控制
可在应用中删除服务器或清除 API Key。卸载器不会删除个人数据。彻底删除前请关闭程序、备份所需资料，再删除上述用户数据目录及不再需要的导出文件。删除数据不撤销已经在远程服务器上创建的账号、节点或 API 凭据。
